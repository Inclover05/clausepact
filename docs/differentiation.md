# Distinct contribution and reuse

Checked 18 October 2026 against the official [hackathon showcase](https://portal.genlayer.foundation/hackathon-winners/) and [ecosystem wall](https://portal.genlayer.foundation/ecosystem-partners/). Public listings are not a complete inventory of submissions. No claim is made that ScopeLock is the first or only scope-change tool.

| Project | Documented focus | ScopeLock's difference |
| --- | --- | --- |
| ClaimLens | Evidence-based factual claim adjudication. | Two authenticated participants approve immutable requirements; decisions concern later scope changes, not factual truth. |
| AutoBounty | Reads submitted GitHub code to verify bounty work before payment. | Does not read code, decide whether work is complete or release money. It judges whether the requested obligation was included in the original brief. |
| BuildersClaw | Evaluates and scores coding challenge submissions with escrow and winner payouts. | No contest, ranking, winner selection or payout. It preserves a bilateral agreement and adjudicates disputed extra requests. |

The distinct contribution is the state machine: creator publication → named contributor's exact-hash acceptance → participant-only scope request → independently validated classification with original clause references. Hash provenance, duplicate protection, mutual permissions and immutable versions are enforced by the new Intelligent Contract.

Reused engineering: selected ClaimLens wallet utilities, endpoint separation, fee review, durable transaction hashes, lifecycle/result provenance checks, and legacy-runtime tooling. Reused infrastructure is disclosed; ClaimLens's branding, claim rubric, database, private drafts, source discovery and historical outcomes are not ScopeLock features or evidence.

The [Builder Program announcement](https://talks.genlayer.foundation/t/introducing-genlayers-incentivized-builders-program/20) describes novelty, complexity and impact as review factors. Only stewards decide acceptance and duplicate treatment. No portal submission has been made by this implementation.
